# Support

## Usage questions

Open a GitHub issue for reproducible questions about installation, package
exports, native JSON behavior, or the documented script-element text context.
Include the package version, Node.js version, minimal input, actual output, and
expected output.

This open-source utility does not include a response-time or
production-support guarantee.

## Security reports

Do not report suspected vulnerabilities in a public issue. Follow
[`SECURITY.md`](./SECURITY.md).

## Out of scope

General HTML sanitization, application-specific template review, browser
security architecture, CSP deployment, and output encoding for other contexts
are outside this project's support boundary.
